# eece2160-example-code
Code examples for EECE.2160: ECE Application Programming at UMass Lowell,
  as taught by Prof. Michael Geiger starting in 2011.

**11/6/2025**
A few notes about this repository:

* The intent of this repository is to organize all of the example code I have generated over the years.
   * That intent is not currently being met. I would classify the repository as "organized" at best.
   * The good news is that, as of today, I've finally integrated Git with the VS Code install on my work machine and might actually make progress on organizing things the way I want.
   * The bad news is that (1) that organization will take a lot of time, and (2) I am the worst procrastinator I know, so it'll get done "at some point" ... in other words, possibly not at all.

* As for the current "organization":
   * Most subfolders contain example code related to a specific topic. For example, "array_examples" is shockingly full of code about working with arrays. Most folder names are therefore (hopefully) self-explanatory.
   * There are, at present, two exceptions:
      * "PE_code" contains code related to large in-class "programming exercises," in which my students and I developed a decent-sized, semi-interesting program from scratch given a specification. At some point, I should probably upload those specifications to make that folder more useful.
      * "vsproj_2160ex" used to hold a Visual Studio Community project with a whole lot of unorganized example code across several years of work. The code remains; the VS-specific files are gone because there's no reason to keep them. Part of my great reorganization will involve going through the mess of code and moving it to folders where it makes sense.

* One final disclaimer: most of this code was written on the fly during lecture. As such, the usefulness of each file will vary dramatically. Some files will contain nicely written code with abundant relevant comments. Others will be barely one step up from spaghetti code. This can probably go without saying, but YMMV.
